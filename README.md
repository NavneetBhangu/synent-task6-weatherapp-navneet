# synent-task6-weatherapp-navneet

A Python-based weather application that fetches real-time weather data using the OpenWeatherMap API and displays temperature, humidity, wind speed, and weather conditions through a user-friendly command-line interface.

## Features
- Real-time weather updates
- Temperature information
- Humidity details
- Wind speed display
- Weather description

## Technologies Used
- Python
- Requests Library
- OpenWeatherMap API
