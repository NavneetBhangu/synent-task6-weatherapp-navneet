# 🌦️ Real-Time Weather Application

## 📌 Overview

A Python-based Weather Application that fetches real-time weather information using the OpenWeatherMap API. Users can enter a city name and receive current weather details such as temperature, humidity, wind speed, and weather conditions.

## 🚀 Features

* Real-time weather data
* Temperature in Celsius
* Feels-like temperature
* Humidity information
* Wind speed details
* Country and city information
* User-friendly command-line interface
* Error handling for invalid city names

## 🛠️ Technologies Used

* Python
* Requests Library
* OpenWeatherMap API

## 📂 Project Structure

weather_app.py

README.md

## ▶️ How to Run

1. Clone the repository
2. Install required library:

pip install requests

3. Open the Python file and add your OpenWeatherMap API key:

API_KEY = "YOUR_API_KEY"

4. Run the program:

python weather_app.py

5. Enter a city name and view the weather report.
